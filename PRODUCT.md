# Product

## Register

product

## Users

Hospital administrators, doctors, reception staff, billing users, pharmacy staff, diagnostic staff, and ward teams use this app during daily operational work. They need fast access to patient, OPD, IPD, billing, diagnostics, pharmacy, appointment, user, role, and tenant administration workflows.

## Product Purpose

Separate HMS is a tenant-aware hospital management workspace connected to Celiyo admin authentication. Success means each tenant can create users, assign roles, manage module permissions, and run HMS workflows with API access gated by the current user's permissions without requiring repeated logins after role updates.

## Brand Personality

Calm, precise, trustworthy. The interface should feel operational and dependable, with clear density, direct labels, and familiar admin patterns.

## Anti-references

Avoid marketing-page composition, decorative gradients, oversized cards, ambiguous icons, low-contrast muted text, and any permission UI that hides the exact module, resource, action, and scope being granted.

## Design Principles

- Make access control explicit: users should understand what a role grants before saving.
- Keep clinical workflows fast: navigation and permission checks should not add friction to daily tasks.
- Prefer predictable admin patterns: tables, tabs, checkboxes, segmented scope controls, and clear save states.
- Preserve tenant boundaries: every user, role, and permission flow should make tenant context unambiguous.
- Refresh authority quickly: permission changes should update the local session data without forcing a logout.

## Accessibility & Inclusion

Target WCAG AA contrast, visible focus states, keyboard-accessible forms, readable dense tables, reduced-motion-safe transitions, and labels that remain clear for color-blind users without relying on color alone.
